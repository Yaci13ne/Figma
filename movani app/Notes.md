# 🎬 MOVANI – Streaming App

## 🎯 Goal
Design a sleek and intuitive mobile interface for a streaming platform that combines **Movies**, **Series**, **Anime**, and **Cartoons** in one app.  
The aim is to make **content discovery** easy and create a **cinematic feel** while keeping the UI lightweight and consistent.

---

## 🧩 Design Overview
- **Platform:** Mobile (iOS style)
- **Theme:** Dark mode for immersive viewing experience
- **Primary Colors:**  
  - Background: `#1C1C1C`  
  - Accent (navigation bar): `#E7B783` (warm tone for contrast)
- **Typography:** Sans-serif, modern and minimal for readability
- **Style:** Rounded cards, soft shadows, minimal clutter

---

## 🧭 User Flow
1. **Home Page**
   - Displays categories: *Movies*, *Series*, *Anime*, *Cartoon*  
   - Search bar for quick lookup  
   - Top icons for notifications and profile access  
   - Bottom navigation bar for main sections

2. **Series Detail Page**
   - Banner with show cover and quick play icon  
   - Show metadata (genre, rating, release year)  
   - Episode cards with previews  
   - Tabs for *About*, *Cast*, and *Comments*

---

## 💡 Design Decisions
- **Dark Background:** Reduces eye strain and matches entertainment aesthetics (like Netflix and Crunchyroll).  
- **Highlight Color (Beige/Gold):** Used for focus areas (navigation icons, buttons) — adds a premium touch.  
- **Rounded Cards:** Make the interface feel modern and approachable.  
- **Fixed Navigation Bar:** Keeps main actions always accessible to the user.

---

## 🧠 UX Considerations
- **Search Bar:** Positioned prominently to encourage quick interaction.  
- **Tabs (Movies / Series / Anime / Cartoon):** Provide clear content segmentation.  
- **Episode previews:** Visual thumbnails improve engagement and recognition.  
- **Consistent margins and spacing:** Maintain balance and readability.

---

## ⚙️ Features (Prototype)
- Interactive transitions  
- Scrollable episode list  
- Clickable navigation icons and tabs  
- Prototype optimized for 852×393 frame resolution
